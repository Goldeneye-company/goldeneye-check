# История изменений

## 0.1.0 (9 октября 2026)

Первый выпуск.

- `gecheck scan`: поиск секретов в файлах и истории git (gitleaks), проверка зависимостей (osv-scanner), анализ кода на JavaScript, TypeScript, Python и PHP (opengrep), проверка настроек Supabase, Firebase, docker-compose, `.env` и `.htaccess`.
- `gecheck site`: проверка HTTPS, сертификата, заголовков безопасности, cookie, открытых служебных файлов и списков каталогов.
- Отчёты в HTML, Markdown и JSON на казахском, русском и английском языках.
- Индекс защищённости и оценка от A до F, параметр `--fail-on` для CI.
- Установщик повторяет загрузку движков при ошибках сервера.
