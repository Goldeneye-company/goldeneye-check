# Изменения

## 0.1.0 — 9 октября 2026

Первый публичный выпуск.

- `gecheck scan` — проверка кода: секреты в файлах и истории git (gitleaks), уязвимые зависимости
  (osv-scanner), уязвимости в коде JavaScript/TypeScript, Python и PHP (opengrep + правила GoldenEye),
  настройки Supabase, Firebase, docker-compose, `.env` и `.htaccess`.
- `gecheck site` — проверка опубликованного сайта: HTTPS, сертификат, заголовки защиты, cookie,
  открытые файлы и списки каталогов. Только запросы чтения и только для своего сайта.
- Отчёты HTML, Markdown и JSON на казахском, русском и английском; секреты маскируются.
- Индекс защищённости и оценка A–F; код выхода для CI (`--fail-on`).
- Точность: 29 из 29 на учебном проекте без ложных срабатываний; 67 верных из 72 находок на пяти
  открытых проектах (`bench/REALRUN.md`).
