# Чек-лист перед запуском

То, что `gecheck` проверить не может, потому что это живёт не в коде, а в настройках сервисов.
Пройдите по списку перед тем, как показывать проект людям.

## Деньги и лимиты
- [ ] В консолях OpenAI, Anthropic, Google AI выставлен жёсткий лимит расходов в месяц
- [ ] Включены уведомления о расходах в облаке и у ИИ-провайдеров
- [ ] На эндпоинтах с ИИ есть лимит запросов на одного пользователя, а не только общий
- [ ] Длина текста, который пользователь отправляет в модель, ограничена

## Доступы
- [ ] Двухфакторный вход включён на GitHub, хостинге, домене, в облаке и платёжной системе
- [ ] Ключи, которые хоть раз попадали в git или в чат, перевыпущены
- [ ] Ключи для разработки и для боевого сайта — разные
- [ ] У сервисных аккаунтов и токенов минимум прав, не «владелец всего»
- [ ] У бывших участников проекта больше нет доступа

## Данные
- [ ] Supabase: RLS включён на каждой таблице, раздел Advisors → Security без ошибок
- [ ] Firebase: в правилах нет `if true`, доступ только к своим данным
- [ ] База не открыта в интернет напрямую
- [ ] Бэкапы делаются автоматически, и вы хоть раз проверили, что из них можно восстановиться
- [ ] Персональные данные клиентов хранятся там, где этого требует закон вашей страны

## Приложение
- [ ] Вы зашли под двумя разными пользователями и проверили, что первый не видит данных второго
- [ ] Каждое действие, которое меняет или удаляет данные, проверяет, кто его делает
- [ ] Ввод проверяется на сервере, а не только в браузере
- [ ] Ошибки не показывают пользователю технические подробности
- [ ] Загружаемые файлы ограничены по типу и размеру
- [ ] Вход, регистрация и восстановление пароля защищены от перебора

## Сайт
- [ ] `gecheck site ваш-сайт` — без критичных и высоких находок
- [ ] Есть политика конфиденциальности и контакты владельца
