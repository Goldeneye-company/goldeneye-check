# Чек-лист перед запуском

Пункты, которые `gecheck` не может проверить автоматически.

## Расходы

- [ ] В консолях OpenAI, Anthropic и Google AI установлен лимит расходов в месяц.
- [ ] Включены уведомления о расходах у облачного провайдера и у провайдеров нейросетей.
- [ ] Для эндпоинтов, которые обращаются к нейросетям, есть лимит запросов на пользователя.
- [ ] Ограничена длина текста, который пользователь может отправить в модель.

## Доступы

- [ ] Двухфакторная аутентификация включена на GitHub, у хостинга, регистратора домена, облачного провайдера и в платёжной системе.
- [ ] Ключи, которые когда-либо попадали в git или в переписку, перевыпущены.
- [ ] Для разработки и для рабочего сайта используются разные ключи.
- [ ] У сервисных аккаунтов и токенов только необходимые права.
- [ ] У бывших участников проекта отозван доступ.

## Данные

- [ ] Supabase: RLS включён на всех таблицах, в разделе Advisors → Security нет предупреждений.
- [ ] Firebase: в правилах нет `if true`, пользователь имеет доступ только к своим данным.
- [ ] База данных недоступна из интернета напрямую.
- [ ] Резервные копии делаются автоматически, восстановление из них проверено.
- [ ] Персональные данные хранятся с соблюдением требований законодательства вашей страны.

## Приложение

- [ ] Проверено под двумя разными пользователями, что один не видит данные другого.
- [ ] Все операции изменения и удаления данных проверяют права пользователя на сервере.
- [ ] Входные данные проверяются на сервере, а не только в браузере.
- [ ] Сообщения об ошибках не показывают пользователю технические подробности.
- [ ] Загрузка файлов ограничена по типу и размеру.
- [ ] Вход, регистрация и восстановление пароля защищены от перебора.

## Сайт

- [ ] `gecheck site` по вашему домену не находит проблем уровня critical и high.
- [ ] На сайте опубликованы политика конфиденциальности и контакты владельца.

Выполнение всех пунктов не гарантирует безопасность. Если в проекте обрабатываются платежи или персональные данные, имеет смысл заказать ручную проверку: https://goldeneye.kz/ru/audit/
