# Как помочь проекту

## Сообщить о ложном срабатывании или пропуске

Откройте Issue и приложите короткий фрагмент кода, на котором сработало (или не сработало) правило.
**Не вставляйте настоящие ключи и пароли** — замените их на `XXXX`.

## Добавить правило

1. Правило — YAML в `gecheck/rules/` в формате opengrep. В блоке `metadata.ge` укажите:
   `severity` (critical / high / medium / low), `category`, `cwe`, а также `title` и `fix` на трёх языках —
   `ru`, `kk`, `en`. Текст `fix` — что конкретно сделать, без объяснения, как эксплуатировать.
2. Добавьте случай в `bench/make_fixture.py`: уязвимая строка с маркером `GE:Vnn`
   и, если возможно, похожая безопасная строка с маркером `GE:Snn`.
3. Проверьте:

```bash
python -m unittest discover -s tests
python bench/benchmark.py
```

Правило принимается, если оно находит свой случай и не срабатывает на безопасных фрагментах.

## Принципы

- Программа только читает. Никаких изменений в проекте пользователя и никаких атак на сайты.
- Секреты не выводятся целиком нигде: ни в консоли, ни в отчётах.
- Код пользователя никуда не отправляется.
