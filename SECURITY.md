# Reporting a vulnerability

If you find a vulnerability in GoldenEye Check (for example, a report shows a full secret, or the program sends requests other than reads), email info@goldeneye.kz with the subject "GoldenEye Check: security".

Please do not publish details in issues until a fix is released. We will reply within 5 business days.

False positives and missed vulnerabilities in the scanned code are not vulnerabilities in the program. You can report them through issues without including real keys or passwords.
