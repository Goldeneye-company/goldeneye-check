## Критический (16)

### Файл .env хранится в git
- Где: `.env`
- в файле есть значения, похожие на настоящие пароли и ключи
- Как исправить: Выполните git rm --cached .env, добавьте .env* в .gitignore и перевыпустите ключи из этого файла, так как они остаются в истории.
- CWE-538

### Секрет в коде: Stripe secret key
- Где: `.env:1`
- значение sk_liv…P2
- Как исправить: Перевыпустите ключ в консоли сервиса, старый считайте скомпрометированным. Затем перенесите значение в переменную окружения или хранилище секретов.
- CWE-798

### Секрет в публичной переменной NEXT_PUBLIC_SUPABASE_SERVICE_ROLE_KEY
- Где: `.env.local:1`
- Как исправить: Переменные с префиксами NEXT_PUBLIC_, VITE_, REACT_APP_ и EXPO_PUBLIC_ попадают в код, который загружает браузер. Уберите префикс, используйте значение только на сервере и перевыпустите ключ.
- CWE-200

### SQL-запрос собирается форматированием строки
- Где: `api/main.py:19`
- Как исправить: Передавайте значения вторым аргументом: cursor.execute('... WHERE id = %s', (oid,)). Не собирайте SQL через f-строки, % и +.
- CWE-89

### Небезопасная десериализация (pickle, yaml.load)
- Где: `api/main.py:29`
- Как исправить: Для внешних данных используйте JSON или yaml.safe_load. pickle подходит только для своих доверенных файлов.

### Эндпоинт вызывает нейросеть без авторизации

### Внедрение команд ОС

## Высокий (12)

### docker-compose: стандартный пароль базы данных (POSTGRES_PASSWORD)
- Где: `docker-compose.yml:5`
- Как исправить: Задайте длинный случайный пароль через .env, который не хранится в git, и смените пароль на серверах, где этот файл уже использовался.
- CWE-1393

### Уязвимая зависимость: lodash 4.17.15
- Где: `package-lock.json`
- уязвимости: CVE-2020-28500, CVE-2020-8203, CVE-2021-23337, CVE-2025-13465
- Как исправить: Обновите lodash до версии 4.18.0 или новее и пересоберите lock-файл.
- CWE-1395

### Вывод данных пользователя без экранирования (XSS)
- Где: `public/contact.php:4`
- Как исправить: Выводите данные через htmlspecialchars($value, ENT_QUOTES, 'UTF-8').
- CWE-79

### Внедрение заголовков письма
- Где: `public/contact.php:7`
- Как исправить: Не подставляйте пользовательские данные в заголовки письма. Проверяйте адрес через filter_var(..., FILTER_VALIDATE_EMAIL) и удаляйте переводы строк.
- CWE-93

### Вывод данных пользователя без экранирования (XSS)
- Где: `src/server/users.js:23`
- Как исправить: Экранируйте вывод (escape-html или шаблонизатор с автоэкранированием) или возвращайте JSON. HTML от пользователя очищайте через DOMPurify.
- CWE-79

### JWT без проверки подписи (jwt.decode)
- Где: `src/server/users.js:29`
- Как исправить: jwt.decode не проверяет подпись. Для аутентификации используйте jwt.verify(token, secret, { algorithms: ['HS256'] }).
- CWE-347

### Путь к файлу из данных запроса (path traversal)
- Где: `src/server/users.js:33`
- Как исправить: Используйте только имя файла (path.basename), проверяйте его по списку допустимых и убедитесь, что итоговый путь находится внутри нужной папки.
- CWE-22

### Пароль или ключ в исходном коде
- Где: `src/server/users.js:35`
- Как исправить: Перенесите значение в переменную окружения (process.env) и смените пароль или ключ.
- CWE-798

### Запрос по адресу из данных пользователя (SSRF)
- Где: `src/server/users.js:40`
- Как исправить: Разрешайте запросы только к известным доменам. Запретите внутренние адреса (localhost, 10.x, 169.254.169.254) и переходы по редиректам.
- CWE-918

### NoSQL-инъекция через $where
- Где: `src/server/users.js:49`
- Как исправить: Не используйте $where. Пишите условия обычными операторами, например { userId: id, stocks: { $gt: threshold } }, и приводите значения к нужному типу.
- CWE-943

### Отключено автоэкранирование в шаблонах
- Где: `src/server/users.js:53`
- Как исправить: Включите autoescape: true. Если в каком-то месте нужен HTML, отметьте его явно (фильтр safe) и очистите через DOMPurify.
- CWE-79

### Supabase: для таблицы public.profiles не включён RLS
- Где: `supabase/migrations/001_init.sql:1`
- Как исправить: Без RLS таблицу может читать и изменять любой, у кого есть публичный anon-ключ. Выполните alter table public.profiles enable row level security; и добавьте политики доступа.
- CWE-284

- Где: `src/server/users.js:44`
